# 📖 About

This repository contains the practical assignments, Jupyter notebooks, and learning exercises completed during the **NVIDIA Accelerated AI Center of Excellence & GPU Computing Internship** conducted at **Presidency University, Bangalore**.

The internship focuses on building a strong foundation in Artificial Intelligence, Deep Learning, Computer Vision, GPU Computing, and Generative AI using industry-standard tools such as TensorFlow, PyTorch, OpenCV, and Hugging Face.

---

# 🎯 Internship Objectives

- Learn Artificial Intelligence fundamentals
- Build Deep Learning models
- Train models using NVIDIA GPU acceleration
- Understand Computer Vision techniques
- Implement Transfer Learning
- Work with Generative AI models
- Gain hands-on experience with real-world datasets
- Develop practical AI applications

# ▶ Getting Started

Clone the repository

```bash
git clone https://github.com/brahmi-kr/NVIDIA-Internship.git
```

Install dependencies

```bash
pip install tensorflow torch torchvision opencv-python numpy pandas matplotlib scikit-learn transformers gtts
```

Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any notebook and run the cells.
